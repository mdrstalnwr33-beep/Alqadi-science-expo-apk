# تنزيل ملفات Telegram المرفقة

## الحالة
التطبيق حاليًا يفتح رابط رسالة Telegram داخل التطبيق. لا يمكن تضمين Bot Token داخل APK، كما أن Bot API لا يدعم تنزيل الملفات الكبيرة التي تتجاوز حد التنزيل الخاص به. لذلك استخراج PDF من رسالة Telegram يحتاج خدمة وسيطة آمنة تحفظ الـToken خارج التطبيق.

## التصميم المطلوب
1. التطبيق يرسل رابط رسالة Telegram مثل `https://t.me/alwssbi/61` إلى خدمة الوسيط.
2. الوسيط يستخرج الملف المرفق من رسالة القناة.
3. الوسيط يعيد رابط تنزيل مؤقت للـPDF.
4. التطبيق يستخدم مسار PDF الحالي لتنزيل الملف وحفظه في `التنزيلات/المقرر الدراسي`.
5. بعد أول تنزيل يصبح الملف متاحًا دون اتصال.

## الأمان
لا تضع Bot Token داخل التطبيق أو داخل ملفات JavaScript التي تُبنى في APK. يجب تخزينه كـSecret في الخدمة الوسيطة.

## ملاحظة
إضافة البوت كمشرف في القناة تمت، لكن ذلك وحده لا يغيّر التطبيق. التحديث السابق كان يفتح رسالة Telegram فقط. هذه الوثيقة تثبت المتطلب المطلوب للتنفيذ الكامل في المرحلة التالية.
