# تطبيق القاضي للعلوم

نسخة Expo/React Native عربية تعمل فورًا في الوضع التجريبي، وتتحول إلى Firebase عند ضبط متغيرات البيئة.

## التشغيل

```bash
npm install
cp .env.example .env
npm start
```

يمكن الدخول التجريبي باستخدام الكود `2026-01`. ولتشغيل Firebase، أنشئ مشروعًا ثم فعّل Firestore وأدخل بيانات Web App في `.env`.

## مجموعة Firestore المطلوبة

أنشئ مجموعة باسم `access_codes`، وكل مستند فيها يحتوي:

```json
{ "code": "2026-01", "name": "اسم الطالب", "createdAt": "2026-10-13T00:00:00.000Z" }
```

## تنبيه أمني مهم

رمز المعلم في هذه النسخة مناسب للتجربة فقط لأنه متغير عام داخل تطبيق الهاتف. قبل النشر التجاري، يجب استبدال لوحة المعلم بمصادقة Firebase Authentication وقواعد Firestore تمنع الكتابة إلا لحسابات المعلمين.
