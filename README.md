# تطبيق القاضي للعلوم

تحديث شامل لتطبيق Expo/React Native العربي، مع لوحة معلم بحسب المستويات الثلاثة، وواجهة طالب لا تعرض إلا المستوى المرتبط بكوده.

## ما تم تحديثه

- الصفحة الأولى تحتوي على: دخول الطالب، دخول المعلم، وعن الأستاذ محمد القاضي.
- ثلاثة مستويات مستقلة: الأول والثاني والثالث الثانوي.
- لكل مستوى المواد: الكيمياء، الفيزياء، الأحياء.
- داخل كل مادة: الكتب والملازم، الدروس اليومية، الواجبات، الاختبارات، الدرجات، والطلاب الأوائل.
- إدارة طلاب المستوى: إضافة كود، إيقاف/تفعيل، وحذف.
- حفظ الجلسة محليًا حتى تسجيل الخروج.
- حفظ المحتوى محليًا وقراءة الدروس دون اتصال.
- زر تنزيل للملفات، ورفع PDF إلى Firebase Storage عند تفعيل إعدادات Firebase.
- ترتيب لوحة الشرف جاهز لعرض الدرجات المعتمدة.
- زر الرجوع في Android يرجع داخل مسار التطبيق بدل إغلاقه.
- الاختبارات تدعم اختيارًا من متعدد، صح/خطأ، وإجابة نصية، مع منع إعادة المحاولة.
- منع تكرار المحتوى بالعنوان داخل المادة.
- تعديل السيرة ورمز المعلم ورفع صورته إلى Storage.

## التشغيل

```bash
npm install
cp .env.example .env
npm start
```

الوضع التجريبي يعمل بهذه الأكواد:

- `2026-01` للأول الثانوي
- `2026-02` للثاني الثانوي
- `2026-03` للثالث الثانوي
- رمز المعلم: `ALQADI-TEACHER`

## ربط Firebase

انسخ `.env.example` إلى `.env` وضع بيانات Web App الحقيقية لمشروع `alnoor-ed4e7`. فعّل Firestore وStorage، ثم طبّق `firestore.rules` و`storage.rules`. المجموعات المستخدمة هي `students` و`access_codes` و`content` و`grades`، وملفات PDF ترفع إلى `materials/{level}/{subject}`.

## مجموعة Firestore المطلوبة

أنشئ مجموعة باسم `access_codes`، وكل مستند فيها يحتوي:

```json
{ "code": "2026-01", "name": "اسم الطالب", "createdAt": "2026-10-13T00:00:00.000Z" }
```

## تنبيه أمني مهم

رمز المعلم داخل النسخة التجريبية ليس مصادقة إنتاجية. للنشر العام يجب تفعيل Firebase Authentication وإضافة custom claim باسم `teacher=true` لحساب المعلم قبل تطبيق القواعد.

## الإشعارات وPDF

المحتوى والنتائج تظهر فورًا في التطبيق المحلي وتُرفع إلى Firestore/Storage عند ضبط Firebase. الإشعارات الفورية الحقيقية تحتاج Firebase Cloud Functions أو خادمًا يرسل FCM بعد إنشاء المحتوى؛ لا يمكن إرسال FCM آمن من تطبيق العميل وحده. عارض PDF الحالي يحفظ الملف للأوفلاين ويعرض تنبيه العلامة المائية؛ إضافة علامة مائية داخل كل صفحة PDF تتطلب معالجة الملف على خادم موثوق قبل رفعه.
