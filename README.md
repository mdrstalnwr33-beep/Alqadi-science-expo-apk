# منارة العلوم — Noura Science

تطبيق تعليمي للعلوم (الكيمياء، الفيزياء، الأحياء) للطلاب والمعلمين.

## حالة المشروع

إعادة بناء كاملة من الصفر. سيتم تطوير المشروع على مراحل مع بناء APK واختبار كل مرحلة قبل الانتقال للمرحلة التالية.

- Expo / React Native / TypeScript
- Expo Router
- واجهة عربية RTL
- طالب / معلم
- كتب ومذكرات ودروس واختبارات وواجبات ودرجات
