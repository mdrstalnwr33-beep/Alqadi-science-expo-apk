# منارة العلوم — مشروع جديد

مشروع مستقل في البنية عن التطبيق القديم، مع الحفاظ على متطلبات المنتج الأساسية.

## المرحلة الحالية
- Expo SDK 57 + React Native 0.86 + TypeScript.
- Expo Router للتنقل بين الشاشات بدلاً من نظام screen/history المخصص.
- واجهة عربية RTL.
- مسارات مستقلة للدخول، لوحة المستخدم، المادة، الكتب، الدروس، الاختبارات، والواجبات.
- بيانات تجريبية محلية فقط في هذه المرحلة؛ لا يوجد اتصال Firebase بعد.
- GitHub Actions يختبر TypeScript وExpo Doctor ثم يبني APK Release.

## الخطة
1. تثبيت الأساس وبناء APK نظيف.
2. تنفيذ الكتب والملخصات والدروس مع عارض حقيقي للملفات.
3. تنفيذ الاختبارات والحفظ والتسليم والمحاولة الواحدة.
4. تنفيذ الواجبات والمرفقات والتصحيح.
5. إضافة طبقة بيانات Firebase منفصلة ومختبرة، ثم تشديد قواعد الأمان.

لا يتم إدخال Firebase في المرحلة الأولى حتى لا تختلط مشاكل البنية بمشاكل الاتصال السحابي.
